# Security

RuleSend is an early alpha. It has not received an independent security audit. Only the latest alpha is a maintenance target; there is no guaranteed response time or enterprise support commitment.

Please do not post credentials, private rule content, working exploit details, or personal device data in public issues. Use this repository's GitHub **Security → Report a vulnerability** feature when it is enabled. If it is unavailable, open a minimal issue asking the maintainer to establish a private reporting channel, without vulnerability details.

Describe the affected version, deployment model, impact, and a reproduction using synthetic data. The [threat model](docs/THREAT_MODEL.md) documents trust boundaries and residual risks. A compromised Hub administrator or local operating-system account is outside those boundaries.
